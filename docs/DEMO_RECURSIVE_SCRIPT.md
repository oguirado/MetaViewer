# Recursive demo script: "the program inside the program"

This is an unfilmed concept, not a report of released behavior. The implemented
nested entry is display-only: it supplies no inner core, capsule creation,
terminal or socket capability [CITED: `ui/electron/nesting.js`]. A functional
recursive demonstration remains [TARGET]. Use [DEMO_RUNBOOK.md](DEMO_RUNBOOK.md)
for the existing live harness and [DEMO_AGENT_SCRIPT.md](DEMO_AGENT_SCRIPT.md)
for its agent-drive checkpoints.

## What must be true before filming this concept?

The inner instance must actually perform the actions shown. A display-only
nested shell cannot stand in for a functional inner MetaViewer.

Answers: recursive demonstration; nesting limitation; recording honesty
