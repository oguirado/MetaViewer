## Formal invariants, proofs, and counterexamples

### 1. State, refusal atomicity, and custody

**[DERIVED from E9/E11; VERIFIED implementation]** Write core state as `S=(D,J,P,C,R,Q)`: authority domain state `D` (surfaces, leases, pending/draining work, budget), journal `J`, placements `P`, capture state `C`, replay/nonce bookkeeping `R`, and outbound queues `Q`. For a refused valid request, the intended domain invariant is `D'=D, P'=P, C'=C`, except explicitly documented settlement/refusal bookkeeping. It does **not** mean that the audit sequence, POLICY line, replay protection, or requester refusal response must disappear.

The authority transition prepares a candidate, appends its event, then replaces live state; see [core/src/admission/mod.rs:805–823](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/admission/mod.rs#L805-L823). A journal failure therefore prevents installation of that candidate. This source order proves the local write-before-install property; it does not prove that every append is already power-loss durable. The latter requires the separate journal forcing invariant below.

**[DERIVED; INFERRED]** Exclusive custody requires at most one admitted conflicting lease per surface/display, with pending-to-draining transfer preserving custody until settlement. `cancel_surface` moves dispatched work to draining and removes it from pending; `Drain` removes it once. Repeated loss cannot manufacture another pending entry, and a second drain is POLICY. This follows by induction on the remove operation at [core/src/admission/mod.rs:562–610](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/admission/mod.rs#L562-L610). ### 4. Native verification, retained context, and publication fences

**[DERIVED decision predicate; VERIFIED gates]** For a proposal `p`, its retained before-frame `b`, receipt `r`, and after-frame `a`, successful production `wait_verify` requires all of:

- `N`: native evidence exists; its surface equals `p.surface_id`; focus_verified=true; native_surface_id is nonempty; native kind equals the proposal action kind (type maps to text); result=ok; `input_mono_ns ≥ input_ts_ns`; and `b.ts_ns ≤ input_ts_ns ≤ r.executed_at_ns`.

- `E`: the requested expectation holds over frame-bound evidence. For changed_region, the nonempty box is in bounds, dimensions match, and at least one compared RGB byte differs.

### 5. Hash-chain game, recovery FSM, and durable closure

**[DERIVED from E1/E2; VERIFIED correspondence]** For canonical record bytes `R_i` and canonical event-sidecar bytes `E_i`, define `T_0=A_0` as64 ASCII zero characters, `T_i=hexSHA256(R_i)`, and `A_i=hexSHA256(ASCII(A_(i−1)) || E_i)`. Under an explicitly hypothetical ideal 256-bit random-oracle model with `Q` total distinct queried inputs, there are `Q(Q−1)/2` input pairs, each colliding with probability `2^-256`. ### 6. Queues, waits, expiry, and bounded frame batches

**[DERIVED deterministic queue invariant]** For capacity `C=256`, an interval starting with occupancy `q0` and cumulative offered arrivals `A` and completed dequeues `D` avoids overflow only if every prefix satisfies `q0+A−D≤256`. This follows by adding one for each enqueue and subtracting one for each dequeue. A 257th send without any dequeue necessarily overflows; a reserved terminal slot changes diagnostic delivery, not ordinary capacity. Constants and overflow handling are [core/src/wire/mod.rs:13–17](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/wire/mod.rs#L13-L17), [core/src/serve/mod.rs:415–430](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L415-L430).

**[DERIVED conditional rate bound]** Under an explicitly fluid approximation with arrival rate λ, service rate μ, and λ>μ, backlog grows as `q(t)=q0+(λ−μ)t` until full. Hence fill time is `(256−q0)/(λ−μ)`; from empty at 100 arrivals/s and 60 sends/s it is 6.4 s. A discrete test should use explicit enqueue/dequeue events because packet rounding changes the exact first overflow instant. With arbitrary arrivals and no distributional hypothesis, there is no universal loss probability below one for any finite cap.

**[DERIVED waiter bound]** At most 256 waits per peer are admitted by [core/src/serve/tools.rs:276–289](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/tools.rs#L276-L289). That is an allocation guard, not a proof that results fit. Register 256 waits for one pending proposal; when its receipt arrives while that agent's writer is blocked, the raw receipt plus 256 results offers 257 messages. Overflow is possible even with an initially empty ordinary queue. A reserved terminal message can report the condition while ordinary replies are abandoned; applications must reconnect/refresh. A serialized-payload upper estimate is `256×1 MiB=256 MiB` plus one terminal envelope at most 1 MiB, using the wire cap. This is not an RSS bound: decoded allocations, queue metadata, blocked writes, and peer count also matter.

**[VERIFIED expiry distinction]** A NotFound pixel-read error calls the frame metadata/regression precheck then returns `Ok(None)` at [core/src/serve/mod.rs:601–619](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L601-L619). Other read errors propagate. A digest mismatch is InvalidData from the verified reader; it does not enter NotFound. The precheck still rejects a generation regression at [core/src/serve/mod.rs:556–583](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L556-L583). Thus ordinary expired publication drops pixels without retiring the daemon; malformed/digest-invalid publication fails closed. This closure does not make equal generations fresh.

**[VERIFIED budget proof fixture; INFERRED limit]** The recovery/expiry fixture binds proposal max_ms to the 30-second idle deadline, and includes a control that dispatch at that exact deadline refuses BUDGETEXCEEDED at [core/src/serve/regression.rs:559–609](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/regression.rs#L559-L609). It repairs the old fixture's prematurely exhausted budget. The control proves dispatch-budget behavior, not by itself every transport idle-disconnection behavior.

**[DERIVED bounded-batch properties; VERIFIED guards]** A daemon batch has at most 32 envelopes at [core/src/serve/mod.rs:1892–1909](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L1892-L1909). Coalescing stops at a non-frame or a non-increasing generation, checks sender/replay for skipped envelopes, and disables skipping on surfaces with active recordings: [core/src/serve/mod.rs:664–716](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L664-L716), [core/src/serve/mod.rs:767–799](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L767-L799). Therefore increasing superseded frames may be omitted by design, while a non-increasing generation reaches the route instead of being skipped by that lookahead. Equality still has the separate admission defect. Frames on recording surfaces are processed individually. Large-frame reads are offloaded at [core/src/serve/mod.rs:802–818](https://github.com/oguirado/MetaViewer/blob/ae9361bb3d645eee1976ec8d739dc358b572561b/core/src/serve/mod.rs#L802-L818); waiters are polled and the loop yields after batches. These facts remove the earlier unlimited drain of ready daemon messages. They do not prove a 1000 ms bound under arbitrary scheduler or storage delay. The finite 3.456 MB burst test is an empirical oracle to execute, not a universal timing theorem.

### 8. Statistical and combinatorial obligations

**[DERIVED fixed-N flake bound]** Assume independent, identically distributed test outcomes with constant failure probability p, and choose N before running. The probability of zero failures is `(1−p)^N`. For a one-sided confidence level 95%, solve `(1−p_U)^N=0.05`, giving `p_U=1−0.05^(1/N)`. With N=3, `p_U=0.6315968501`: three greens alone only bound the rate by about 63.16% under these assumptions. To make p_U<0.01, solve `N>ln(0.05)/ln(0.99)=298.072...`, so the smallest integer is **299**; `p_U=0.0099691468`. Stop-on-first-failure is compatible with declaring success only after the preselected 299; repeatedly restarting until three greens is not this experiment. Correlated CI runs or changing code invalidate the IID interpretation.

**[DERIVED pair-order coverage]** For any fixed unordered pair of operations, a uniform random permutation places either member first with probability 1/2. Across K independent permutations, missing a specified orientation has probability `2^-K`; missing either has probability `2^(1−K)`. There are `N(N−1)/2` unordered pairs. A union bound therefore gives `P(any missing orientation)≤N(N−1)2^-K`. At N=12, K=32 this is `132/2^32=3.073364496×10^-8`. Fixed PRNG seeds 0..31 do not themselves prove independent uniform sampling. Require an actual pair-coverage bitmap, and add a base permutation and its exact reverse: those two deterministically cover both relative orientations of every pair, although they do not cover every state-dependent or higher-order interaction.

**[DERIVED E8 interleavings]** K atomic per-actor transactions have K! serial orders. If each actor instead has an ordered read then write, there are `(2K)!/2^K` linear extensions: start with all (2K)! label permutations, then exactly half obey each disjoint actor's read-before-write order, giving the divisor 2^K. At K=2,3,4 the counts are 6,90,2520 versus 2,6,24 atomic orders. Scheduler stress alone does not enumerate these. Proposed deterministic barriers and a shadow state model below turn the counts into finite test oracles.
